# Запомни слово - Обучающая игра

## Описание проекта

"Запомни слово" - это интерактивное веб-приложение на основе Vue 3 и Vite, предназначенное для изучения иностранных слов. Приложение представляет собой обучающую игру, в которой пользователи могут учить новые слова и проверять свое понимание переводов.

## Особенности

- Интерактивная карточная система для изучения слов
- Визуальное отображение прогресса с индикатором здоровья
- Возможность переворачивать карточки для просмотра переводов
- Система оценки знаний (правильно/неправильно)
- Адаптивный дизайн для комфортного использования
- Динамическая загрузка слов с сервера

## Технологии

- Vue 3 (Composition API)
- Vite (быстрая сборка и разработка)
- JavaScript (ES6+)
- CSS (с использованием scoped стилей)

## Установка и запуск

1. Убедитесь, что у вас установлены Node.js (версия 14 или выше) и npm.

2. Клонируйте репозиторий:
   ```bash
   git clone <url_репозитория>
   ```

3. Перейдите в папку проекта:
   ```bash
   cd <имя_проекта>
   ```

4. Установите зависимости:
   ```bash
   npm install
   ```

5. Запустите приложение в режиме разработки:
   ```bash
   npm run dev
   ```

Приложение будет доступно по адресу http://localhost:5173

## Использование

1. Нажмите кнопку "Начать игру" для загрузки новых слов
2. Кликните на карточку, чтобы перевернуть её и увидеть перевод
3. После просмотра перевода, подтвердите правильность знания слова, нажав "Да" или "Нет"
4. Следите за индикатором здоровья, который отражает ваш прогресс

## Зависимости

- @vitejs/plugin-vue: ^6.0.1

- `npm run dev` - запуск в режиме разработки
- `npm run build` - сборка для продакшена
- `npm run preview` - предварительный просмотр сборки
- `npm run lint` - проверка кода

## Примечания

Приложение ожидает API-сервер на http://localhost:8080/api/random-words, который должен возвращать массив объектов со свойствами `word` и `translation`.
